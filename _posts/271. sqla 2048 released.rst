SQLAlchemy 2.0.48 is now available.

Release 2.0.48 fixes a single potential concurrency issue which could impact
custom "on connect" routines, particularly those used by the SQL Server
dialect.

Links to the detailed changelog for 2.0.48 is at `Changelog </changelog/CHANGES_2_0_48>`_.

SQLAlchemy 2.0.48 is available on the `Download Page </download.html>`_.
